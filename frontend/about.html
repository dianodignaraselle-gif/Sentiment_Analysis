About This System

This system performs sentiment analysis on TikTok comment sections to evaluate the public perception of foundation cosmetic products. It uses BERT (Bidirectional Encoder Representations from Transformers) model to understand the context of comments and classify them into Positive, Neutral, and Negative sentiments.

Technology

  • Python
  • BERT (Hugging Face Transformers)
  • PyTorch
  • Flask REST API
  • HTML / CSS / JavaScript

Developed For

  • Research and academic purposes
  • Insights for cosmetic product evaluation and improvement
  • Understanding customer sentiment at scale
